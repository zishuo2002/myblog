## On the reliability of large language models for causal discovery：

该论文通过开展实验（OLMo 和 BLOOM 因公开了预训练语料（Dolma 和 ROOTS）而作为主力分析模型），研究了大语言模型（LLM）在**因果发现**任务中的可靠性，得出三个结论：

- 记忆（预训练数据）驱动，泛化能力弱
- （预训练数据）错误信息会"污染"置信度
- 上下文严重影响结果



## Discovery of the Hidden World with Large Language Models（COAT）

核心思路是：让大语言模型（LLM）和因果发现算法（CD）互相配合，从**非结构化数据**（文本、图像等）中挖掘因果关系。

流程：

- 因子提议：非结构化数据 -> LLM -> 因子
- 因子标注：因子 + 非结构化数据 -> LLM -> 因子的结构化数据
- 因果发现 + 反馈 ：因子的结构化数据 -> 因果发现算法 if 效果不好 循环 



## IRIS: An Iterative and Integrated Framework for Verifiable Causal Discovery in the Absence of Tabular Data

传统因果发现面临的痛点：

- **统计方法的问题：** 需要大量高质量的结构化表格数据，收集成本极高；还要求预先定义好所有变量；并且依赖两个不现实的假设——"无环假设"（现实中存在大量反馈循环）和"因果充分假设"（所有相关变量都已被观测到）。
- **LLM方法的问题：** 虽然不需要表格数据，但只能"背诵"训练数据中已知的因果关系，无法发现新的、未曾记录过的因果关系——论文称之为"因果鹦鹉"问题。

IRIS 的核心思路是**把两类方法的优点结合起来**，同时用LLM自动采集数据，从而摆脱对预先存在数据集的依赖。

##### 组件一：数据收集与值提取

1、文档检索

系统用 Google Search API 检索相关文档，采用"逐步缩减法"。初始查询为多变量，逐论递减到单变量查询。多变量查询能找到同时讨论多个变量关系的高相关文档，单变量查询则保证覆盖面不遗漏。变量越多的查询，获取的文档数 k 也设置得越大。整个过程持续到文档总量达到预设阈值为止。

2、值提取

拿到文档后，系统要把非结构化文本转化成表格。对每一篇文档和每一个变量的组合，用 LLM 判断"这篇文档能否推断出该变量的存在？"答案是 True 或 False。LLM 被要求按照链式思维（CoT）格式作答，先分析再给出结论，格式固定便于自动提取。

最终构建出一张矩阵：行是文档，列是变量，每个格子填 True/False，这就是后续统计算法需要的结构化数据表。

##### 组件二：混合因果发现

1、统计路径

把上一步生成的结构化数据表输入统计因果发现算法，输出结果记为 Gs。

2、LLM 验证路径

对每一对变量 (X, Y)，系统先生成一个声明，比如"吸烟导致肺癌"，然后专门去学术数据库检索同时包含"吸烟"和"肺癌"的文献，让 LLM 判断每篇文献是支持、反驳还是与该声明无关。

判定规则是：如果多数文献支持，就把这条关系纳入验证图 Gv；如果多数文献反驳，就记录下来准备在合并时删除。

3、图合并

把 Gv 中高置信度的验证关系加到 Gs 里，同时把被强力反驳的边从 Gs 中删掉。

##### 组件三：缺失变量提议

1、变量抽象

系统让 LLM 读取已收集的文档，对每篇文档询问："有哪些变量可能影响或被初始变量集影响？"

LLM 被要求先尽量多提候选，再通过去除语义重叠、缩短名称来精炼，最后给出一个最可靠的候选变量。所有文档跑完后，得到一批候选变量集合。

2、变量筛选

候选变量可能很多，需要筛掉不可靠的。系统用两种方法并行打分：

**因果关系验证**：复用组件二的 LLM 验证方法，检验新候选变量和每个初始变量之间是否存在有文献支持的因果关系（正向和反向都查），通过的变量直接加入扩展集。

**点互信息（PMI）打分**：PMI 衡量两个词在文档中共同出现的频率是否超出随机水平。公式是
$$
\text{PMI}(z_i, z_j) = \log \frac{o(z_i, z_j)}{o(z_i) \cdot o(z_j)} 
$$
其中共现次数和单独出现次数都通过 Google Search API 的返回结果数来估算。

PMI 越高，说明两个变量关联越紧密，越可能存在因果关系。计算每个候选变量与所有初始变量的 PMI 总分，取 top-k 加入扩展集。

3、迭代扩展

筛选出的新变量加入变量集之后，整个流程从头再来：重新检索文档、重新提取值、重新做因果发现。每轮迭代都在原有因果图的基础上继续扩展，直到没有新变量被提议为止。这个机制让 IRIS 能从少量初始变量出发，逐步探索出一张覆盖范围更广的因果图。
