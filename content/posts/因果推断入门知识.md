## 辛普森悖论

#### 1、基本概念

当一个数据集被分成若干子组进行分析时，某个趋势在每个子组中都存在，但当这些子组合并后，该趋势却会减弱甚至反转，传统统计方法无法很好的解决这个问题

#### 2、数学解释

#### 案例1:

##### 男性数据

|        | 未康复 | 康复 | 总计 | 康复率 |
| ------ | ------ | ---- | ---- | ------ |
| 给药   | 6      | 81   | 87   | 0.93   |
| 未给药 | 36     | 234  | 270  | 0.87   |

##### 女性数据


|        | 未康复 | 康复 | 总计 | 康复率 |
| ------ | ------ | ---- | ---- | ------ |
| 给药   | 71     | 192  | 263  | 0.73   |
| 未给药 | 25     | 55   | 80   | 0.69   |

**总体数据**

|        | 未康复 | 康复 | 总计 | 康复率 |
| ------ | ------ | ---- | ---- | ------ |
| 给药   | 77     | 273  | 350  | 0.78   |
| 未给药 | 61     | 289  | 350  | 0.83   |

**可以得出以下结论：**

- 总体康复率：给药 < 未治疗
- 男性康复率：给药 > 未治疗
- 女性康复率：给药 > 未治疗

##### 人为定义：

|      | X    | Y      | Z      |
| ---- | ---- | ------ | ------ |
| 0    | 女性 | 未康复 | 未给药 |
| 1    | 男性 | 康复   | 给药   |

对于分类数据
$$
(1):P(Y=1|X=1,Z=1)=0.93\\
(2):P(Y=1|X=1,Z=0)=0.87\\
(3):P(Y=1|X=0,Z=1)=0.73\\
(4):P(Y=1|X=0,Z=0)=0.69 \\
$$
对于总体数据
$$
A:P(Y=1|Z=1)=0.78\\
B:P(Y=1|Z=0)=0.83\\
$$

令`P(X=1|Z=1)`为`q`，`P(X=1|Z=0)`为`q'`，有：
$$
A=(1)*q+(3)*(1-q)\\
B=(2)*q'+(4)*(1-q’)
$$
`q `和` q' `取值范围都为`0～1`，因此 A 的概率介于 (1) 和 (3) 之间，B 同理，A 的范围为 0.73 到 0.93，B 的范围为 0.69 到 0.87，通过改变`q` 和`q'` 取值可以影响 A 和 B 的大小关系 

通过观察数据可以发现，女性恢复普遍比男性差，且如果改变不同性别人群的数量会改变结果，因果图为：

```
 			  年龄
 		↙ 	 			 ↘   
是否给药    →    康复率

```

可以看到年龄作为一个混淆因素对最终结果产生影响，因此应该关注分组数据

####  案例2：

|                | 未给药 | 给药 |
| -------------- | ------ | ---- |
| 正常血压的患者 | 0.93   | 0.87 |
| 高血压的患者   | 0.73   | 0.69 |
| 整体数据       | 0.78   | 0.83 |

但是实际因果图为：

```
 			 血压水平
 		↗ 	 			 ↘   
是否给药    →    康复率

```

如果关注分组数据意味着剔除了血压水平的因素，只关注到了药物对患者的副作用，但是整体数据上药物可以通过降低患者血压，进而促进患者康复

## 图模型

#### 基本概念：

##### 1、图的构成：节点 node + 边 edge

例如： X - Y - Z

X 和 Y 有边连接，则称 X 和 Y **相邻（ adjacent ）**

##### 2、全图 complete graph：所有节点都相邻

##### 3、路径

指两个节点之间一连串的路径（例如 X 到 Z）

##### 4、Parent 和 Child：有向边的起始和结尾

##### 5、ancestor和descendent

路径中某节点的上游节点都为 ancestor，下游节点都为 descendent

##### 6、循环图 cyclic

##### 7、有向无环图 DAG
