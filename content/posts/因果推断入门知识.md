**可以得出以下结论：**

- 总体康复率：给药 < 未治疗
- 男性康复率：给药 > 未治疗
- 女性康复率：给药 > 未治疗

##### 人为定义：

|      | X    | Y      | Z      |
| ---- | ---- | ------ | ------ |
| 0    | 女性 | No Rec | No Trt |
| 1    | 男性 | Rec    | Trt    |

对于分类数据
$$
(1):P(Y=1|X=1,Z=1)=0.93\\
(2):P(Y=1|X=1,Z=0)=0.87\\
(3):P(Y=1|X=0,Z=1)=0.73\\
(4):P(Y=1|X=0,Z=0)=0.69 \\
$$
对于总体数据
$$
A:P(Y=1|Z=1)=0.78\\
B:P(Y=1|Z=0)=0.83\\
$$

令`P(X=1|Z=1)`为`q`，`P(X=1|Z=0)`为`q'`，有：
$$
A=(1)*q+(3)*(1-q)\\
B=(2)*q'+(4)*(1-q’)
$$
`q `和` q' `取值范围都为`0～1`，因此 A 的概率介于 (1) 和 (3) 之间，B 同理，A 的范围为 0.73 到 0.93，B 的范围为 0.69 到 0.87，通过改变`q` 和`q'` 取值可以影响 A 和 B 的大小关系 

通过观察数据可以发现，女性恢复普遍比男性差，且如果改变不同性别人群的数量会改变结果，因果图为：

```
 			  年龄
 		↙ 	 			 ↘   
是否给药    →    康复率
```

可以看到年龄作为一个混淆因素对最终结果产生影响，因此应该关注分组数据

## 图模型

#### 基本概念：

##### 1、图的构成：节点 node + 边 edge

例如： X - Y - Z

X 和 Y 有边连接，则称 X 和 Y **相邻（ adjacent ）**

##### 2、全图 complete graph：所有节点都相邻

##### 3、路径

指两个节点之间一连串的路径（例如 X 到 Z）

##### 4、Parent 和 Child：有向边的起始和结尾

##### 5、ancestor和descendent

路径中某节点的上游节点都为 ancestor，下游节点都为 descendent

##### 6、循环图 cyclic

##### 7、有向无环图 DAG



## 结构因果模型 SCM

变量 X 是变量 Y（outcome） 的**直接原因（direct cause / treatment）** ，可以使用一个因果模型来刻画以上关系
$$
Y=f(X)
$$
此处的因果模型没有反函数，因为因果从时间上是不可逆的

对于以下关系，X 是 Z 的间接原因 **indirect cause**
$$
Z=g(X)\\
Y=f(Z)
$$
可以写成
$$
Y=f(g(X))
$$
X 是 Y 的原因都可以称其为 Y 的一个**原因 cause**

因果模型可以用图来刻画，例如
$$
Y=g(Z)\\
Z=f(x, w)
$$

```
W
  ↘   
X → Z → Y
```

其中变量 X、W 没有父节点，被称为**外生变量 exogenous**，Z、Y 有父节点，被称为**内生节点 endogenous**

```
set u = {X, W}
set v = {Y, Z}
set f = {f, g}
```

## 链状结构 chain

下图中 X、Y、Z 是一种传递关系，被称为链状结构

```
X → Y → Z
↑   ↑   ↑ 
ux  uy  uz

SCM：
u = {ux, uy, uz}
v = {X, Y, Z}
f = {fx, fy, fz}

假设：
fx: X = ux
fy: Y = 100 - x + uy
fz: Z = 100Y + uz
```

可以得出以下关系：

Z and Y are **likely dependent** 

X and Y are **likely dependent** 

X and Z are **likely dependent** 

X and Z are **independent, conditional on Y**

概率上有：
$$
P(Z=z|X=x,Y=c)=P(Z=z|Y=c)
$$


##### 总结：Rule 1

如果 X 和 Z 是链状结构，
$$
X≡Z
$$
控制中间的变量则 X 和 Z 独立
$$
X ⊥ Z\,\,|\,\,Y
$$


因此我们现在再看之前的案例

|          | No Trt          | Trt             |
| -------- | --------------- | --------------- |
| Low BP   | 81/87（0.93）   | 234/270（0.87） |
| High BP  | 192/263（0.73） | 55/80（0.69）   |
| 整体数据 | 273/350（0.78） | 289/350（0.83） |

```
 			 血压水平
 		↗ 	 			 ↘   
是否给药    →    康复率
```

定义：

|      | X      | Y      | Z       |
| ---- | ------ | ------ | ------- |
| 0    | No Trt | No Rec | low BP  |
| 1    | Trt    | Rec    | high BP |

$$
P(Y=1|X=0)=0.78\\
P(Y=1|X=1)=0.83\\
$$

Conditon on Z
$$
P(Y=1|X=0,\,Z=0)=0.93\\
P(Y=1|X=1,\,Z=0)=0.87\\
$$
可以看到在控制血压水平这个条件后，给药后康复率下降





## 叉状结构 fork

下图中 X、Y、Z 是一种传递关系，被称为链状结构

```
Y ← X → Z
↑   ↑   ↑ 
uy  ux  uz

SCM： 
u = {ux, uy, uz}
v = {X, Y, Z}
f = {fx, fy, fz}

假设：
fx: X = ux
fy: Y = 4x + uy
fz: Z = x/10 + uz
```

可以得出以下关系：

X and Y are **likely dependent** 

X and Z are **likely dependent** 

Y and Z are **likely dependent** 

Y and Z are **independent, conditional on X

##### 总结：Rule 2

控制混淆变量则 Y 和 Z 独立
$$
Y ⊥ Z\,\,|\,\,X
$$




## 碰撞结构 Collider

下图中 X、Y、Z 是一种传递关系，被称为链状结构

```
X → Z ← Y
↑   ↑   ↑ 
ux  uz  uy

SCM： 
u = {ux, uy, uz}
v = {X, Y, Z}
f = {fx, fy, fz}

假设：
fx: X = ux
fy: Y = uy
fz: Z = x + y + uz
```

可以得出以下关系：

X and Y are **dependent** 

X and Z are **likely dependent** 

Y and Z are **likely dependent** 

Y and Z are **dependent, conditional on X**

##### 总结：Rule 2

控制碰撞变量则 X 和 Y 相关
$$
Y ≡ Z\,\,|\,\,X
$$
