# 组学

### 一、基础知识

#### 1、概述

DNA-RNA-蛋白质-代谢产物，分别对应基因组学、转录组学、蛋白组学、代谢组学

#### 2、各代测序技术

| 代际               | 代表技术                         | 原理               | 读长          | 通量   | 错误率        |
| ------------------ | -------------------------------- | ------------------ | ------------- | ------ | ------------- |
| **一代**           | Sanger 测序（毛细管电泳）        | 双脱氧链终止法     | 700~1000 bp   | 极低   | 极低（<0.1%） |
| **二代**           | Illumina SBS、Ion Torrent        | 边合成边测序       | 150~300 bp    | 极高   | 低（0.1~1%）  |
| **三代**           | PacBio SMRT、Oxford Nanopore     | 单分子实时测序     | 10 kb~100 kb+ | 中等   | 较高（1~15%） |
| **四代**（概念中） | 纳米孔蛋白改进、电子显微镜测序等 | 直接读取碱基电信号 | 理论上更长    | 研究中 | 持续改进      |

#### 3、SBS 实验流程

从血液、组织、唾液等样本中提取基因组 DNA，质检后将大分子 DNA 切成 **150~300 bp** 的小片段，方法：超声波打断、酶切打断，建库

```
片段化DNA
   ↓  末端修复（补平末端）
   ↓  加A尾（3'端加单碱基A）
   ↓  连接接头（Adapter，含index标签）
   ↓  PCR扩增
→ 文库（Library）
```

###### 接头的作用是让 DNA 片段能结合到测序芯片上，index 用于混样测序时区分样本。

捕获富集

##### Panel —— 靶向捕获 / 扩增子法

**方法一：杂交捕获法**

```
文库 + 特异性探针（biotinylated probes）
         ↓ 杂交（探针与目标区域互补结合）
         ↓ 链霉亲和素磁珠捕获
         ↓ 洗去非目标片段
→ 只剩目标基因的 DNA 片段
```

**方法二：扩增子法（Amplicon）**

```
直接用多重PCR引物，只扩增目标区域
→ 更快、更便宜，但均一性略差
```

> 结果：数百个目标基因被高度富集，其余基因组被丢弃，因此可以用**极高深度**（1000×+）测序，适合检测低频突变（如 1% 的肿瘤突变）。

------

##### WES —— 全外显子捕获

原理与 Panel 杂交捕获相同，但探针覆盖**全部外显子**（~50 Mb）：

```
文库 + 全外显子探针库（如 Agilent SureSelect、IDT xGen）
         ↓ 杂交捕获（通常 16~24h）
         ↓ 磁珠富集、洗脱
→ 外显子区域富集文库
```

探针库覆盖约 **20,000 个基因**的外显子，捕获后上机测序，深度通常 100×～200×。

------

##### WGS —— 无需捕获，直接测序

```
文库构建完成后，直接上机
→ 所有片段均匀测序，无任何富集步骤
```

最简单，但代价是要测 **3 Gb** 的全基因组，成本高、数据量大，平均深度通常 30×～60×。

------

#### 第五步：上机测序（以 Illumina 为例）

```
文库 → 流动池(Flow Cell)
         ↓ 桥式扩增（形成簇 Cluster）
         ↓ 边合成边测序（SBS）
              · 加入荧光标记的dNTP
              · 每轮激光扫描记录碱基
              · 切除荧光基团，进入下一轮
→ 输出：FASTQ 文件（reads + 质量值）
```

------

### 三、生信分析流程

#### 通用分析流程

```
FASTQ（原始数据）
   ↓  质控：FastQC / Trimmomatic（去低质量、去接头）
   ↓  比对：BWA-MEM（将reads比对到参考基因组 hg38）
→ BAM 文件（比对结果）
   ↓  排序、去重（Picard MarkDuplicates）
   ↓  碱基质量重校正（BQSR，GATK）
→ 精处理 BAM
   ↓  变异检测（Variant Calling）
→ VCF 文件
   ↓  注释（Annovar / VEP）
→ 最终报告
```

------

#### 变异检测方法对比

| 变异类型            | 工具                 | Panel   | WES  | WGS      |
| ------------------- | -------------------- | ------- | ---- | -------- |
| SNV/Indel（胚系）   | GATK HaplotypeCaller | ✅       | ✅    | ✅        |
| SNV/Indel（体细胞） | Mutect2              | ✅高灵敏 | ✅    | ✅        |
| CNV                 | CNVkit / GATK CNV    | 有限    | 较好 | ✅        |
| SV（结构变异）      | Manta / LUMPY        | ❌       | 有限 | ✅        |
| 甲基化              | Bismark              | ❌       | ❌    | 需BS-seq |

------

#### 变异注释

检测到变异后，需要注释其**生物学意义**：

```
VCF
 ↓
Annovar / VEP
 ├── 基因功能影响（同义/错义/无义突变）
 ├── 人群频率（gnomAD、1000 Genomes）
 ├── 致病性预测（SIFT、PolyPhen-2、CADD）
 ├── 数据库比对（ClinVar、OMIM、COSMIC）
 └── 临床分级（ACMG 5级分类）
```
